# 新场景留出评测 v1

20 条合成记忆、24 个正例查询、14 个负例，覆盖四种记忆类型、相邻时段、未知事件时间、
同主题但缺少所问信息的事实，以及多目标查询。全部资料为虚构，不涉及真实档案或个人信息。
文档通过带类型的写入 API 入账，评估检索与治理，不是自然语言抽取的留出评测。

本集由同一开发代理在修复后编写，未用于此前提示或代码调整；在第一次模型调用前，记录
数据集、标签及检索策略源码 SHA-256。冻结后不修改查询、标签、阈值，也不根据本集结果调参。
因此它是新增开发方留出集，不是第三方独立标注或双盲评测；未来用于修复后将变成回归集。

沿用原检索集的四项门槛，同时预先要求正例返回的非目标候选比例不高于 10%。原驱动的
release_gate 不包含后一项，最终报告必须单独给出该精准性门槛，不能仅引用 release_gate。

本集不写入通用 global 偏好，以免把合法的跨主题风格注入错误计为负例命中。这里的
负例标准是“没有能够回答所问信息或适用于该任务的已存记忆”，不是“同主题一律不许召回”。
权限隔离沿用独立验证，不把询问其他用户内容的空结果当作充分的租户隔离证明。

## 后续使用身份

2026-10-20 已根据本集失败类型开展后续修复，因此本集从该阶段起作为回归集。原始数据、标签、冻结清单与首次失败证据保留；改动检索策略后需显式传入 `scripts/eval-resume-final.py --regression`，仍校验数据哈希，不再称新结果为独立留出。后续新场景验证使用 retrieval-holdout-v2。
