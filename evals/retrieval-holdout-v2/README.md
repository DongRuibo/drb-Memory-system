# 新场景留出集 v2

20 文档、24 正例、16 负例，使用苗圃生产记录场景。数据、标签与门槛在本次实现和模型调用前冻结；检索策略完成后、首次评测前另存 policy-freeze.json。

要求 Recall@3 ≥ 0.85、MRR ≥ 0.75、负例零命中、遗忘后零注入、正例非目标候选比例 ≤ 10%。不含通用偏好，按目标标签计候选；多目标问题允许为任一请求部分提供直接依据。

该集由同一开发方编写，并非外部独立或生产流量。修复前已参考 v1 的失败类型，因此只能说明新场景迁移。v1 自本次起作为回归集，原始冻结文件和失败证据保留。不得为通过本集而改查询、标签或阈值；若继续调参，应将本集转为回归并建立新的留出。
