# 简历项目条目：Agent 记忆治理系统

**技术栈：Rust / Axum / Tokio / SQLx / PostgreSQL / pgvector / Mem0 / Qwen3 / DeepSeek / React**

- 开发以 PostgreSQL 为权威账本的 Agent 记忆服务，使用 Mem0＋pgvector 维护检索投影；实现
  来源追溯、版本修正、冲突隔离与审核、Outbox 投递、权限回查和遗忘后的即时拒读。
- 区分通用偏好、场景偏好、用户资料、项目事实和事件记忆；结合向量／关键词召回、候选排序
  与答案适用性复核，编译并消费可审计的 Context Pack，避免过期、争议或越权内容进入回答。
- 完成真实模型的跨会话回忆、修正、审核、隔离及遗忘验证；152 项普通 Rust 测试与 21 项
  PostgreSQL 集成测试通过。在 20 文档、19 正例、5 负例的合成检索集上，Recall@3／MRR 为 1，
  负例零命中、遗忘后零注入；另验证 22 例抽取与安全边界及 10 轮 Episode 整理。

## 面试时必须说明的边界

这些是单机合成验证结果，不是生产规模或泛化质量保证。向量／候选排序使用本地缓存的
Qwen；抽取、回答和适用性复核使用 DeepSeek API。Mem0 是投影适配层，治理由自研服务实现。
固定集正例结果仍有 20.83% 非标注目标候选。新增预先冻结的新场景集（20 文档、24 正例、
14 负例）Recall@3／MRR 为 1，但负例误召回 4/14、非目标候选 12.90%，未通过全部门槛。
该集由开发方编写，不是外部独立标注；同主题事实不一定能回答密码、具体故障现场或精确时间。
候选精准性和修复后浏览器操作验收仍有剩余工作。不要把“Release Gate PASS”写成生产上线验收通过。
